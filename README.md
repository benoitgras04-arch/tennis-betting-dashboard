# Tennis Betting Dashboard

Personal dashboard for tracking tennis betting performance over time.

## Features

- Daily betting overview (ATP / WTA)
- Performance tracking and bankroll evolution
- Statistical analysis by surface, bookmaker, value edge
- Model calibration metrics
- Full betting journal with filters and CSV export

## Tech stack

- Python 3.10+
- Streamlit
- Pandas, Plotly

## Disclaimer

This dashboard is a **personal tracking tool** for educational purposes. 
It is not a betting service and does not provide professional advice.
